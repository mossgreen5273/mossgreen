アリスのルールThe Alice rule

駒は自分が今いる盤のルールで移動・捕獲します。移動が終わると、もう片方の盤の同じマスへ瞬間移動します（その盤のそのマスが空いている場合のみ）。
A piece moves and captures using the board it currently sits on. After the move, it teleports to the same square on the other board — only if that square is empty there.
王手は、玉が今いる盤の駒からのみ発生します。持ち駒はどちらの盤にも打てます。
Check only comes from pieces on the same board as the king. Hand pieces may be dropped on either board.
