平安将棋のルールHeian rule

8×8盤、6種類の駒（歩・香・桂・銀・金・玉）のみ。飛車も角行もありません。
Played on an 8×8 board with only 6 piece types (pawn, lance, knight, silver, gold, king). No rook, no bishop.
取った駒は持ち駒にならず、そのまま盤外へ除かれます（打つことはできません）。
Captured pieces are removed from the game entirely — there is no hand, no drops.
玉同士だけが盤上に残った場合は引き分けです。
If only the two kings remain on the board, the game is a draw.
